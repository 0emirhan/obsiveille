# Bienvenue dans ta veille

1. Si Obsidian te propose d'activer les modules communautaires (mode restreint),
   accepte — le plugin **Veille** est déjà sélectionné.
2. Réglages → Veille : colle le **jeton** qu'on t'a donné (l'adresse du serveur
   est déjà pré-remplie).
3. Clique sur l'icône satellite dans la barre latérale (ou lance la commande
   *Veille : synchroniser maintenant*).

La note **Accueil** apparaîtra après la première synchro : les articles récents,
en mur d'images.

L'habillage (`snippets/veille.css`) est déjà activé. S'il ne s'affiche pas : Réglages →
Apparence → Snippets CSS, vérifie que **veille** est bien coché.
